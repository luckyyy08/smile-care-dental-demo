# 🦷 Smile Care Dental Clinic — Website

A modern, accessible, and fully responsive single-page website for **Smile Care Dental Clinic**, a premier dental clinic in Nashik, Maharashtra.

## 🚀 Live Features
- **Mobile-First Responsive Design**: Optimized across 360px, 390px, 768px, and 1200px+ viewports without horizontal scrolling.
- **Sticky Navigation**: Smooth scroll, backdrop blur effect, and mobile hamburger drawer.
- **Services Grid**: 1 column on mobile, 2 on tablet, and 3 on desktop.
- **Why Choose Us**: Highlighting advanced sterilization, modern diagnostics, and painless care.
- **Appointment Booking Form**: Single-column layout with real-time field validation, date constraints, numeric keypad for phone inputs, and pre-filled WhatsApp confirmation.
- **Accessible FAQ Accordion**: Keyboard-friendly with large touch targets and aria-expanded attributes.
- **Google Maps Integration**: Sensible fixed height, 100% responsive width embed.
- **Sticky Mobile Quick Contact**: Bottom Call and WhatsApp bar with safe-area padding for mobile devices.

## 📁 Project Structure
```
├── index.html        # Main semantic HTML5 markup
├── style.css         # Mobile-first custom CSS stylesheet
├── script.js         # Vanilla JavaScript (nav, drawer, accordion, form validation)
├── css/
│   └── style.css     # Mirror copy for modular paths
├── js/
│   └── main.js       # Mirror copy for modular paths
└── reference/        # Design references and assets
```

## 🛠️ Tech Stack
- HTML5 & CSS3 (Custom Variables, Flexbox, CSS Grid)
- Vanilla JavaScript (ES6+, No framework dependencies)
- Bootstrap 5.3.3 (Grid utilities)
- Google Fonts (`DM Serif Display` & `Outfit`)

## 💻 How to Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/luckyyy08/smile-care-dental-demo.git
   ```
2. Open `index.html` directly in your browser or run with a local server:
   ```bash
   npx serve .
   ```
   Or with VS Code Live Server.
